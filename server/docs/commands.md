# Описания архитектуры программы :
## Компоненты системы:
- Сервер - программа, которая занимается обработкой заданий , взаимодействует с тестовыми платами, хранением собранных даных и заданий/сценарий .

- Клиент(клиенты) - программа , которая занимается подготовкой задания для обработки сервером, его передачей и приёмом результатов.
## Хранимые данные :
- Сценарий(Scenario) -  Сценарий для тестирования дизайна.

- Задание(Task) - единица запуска сценария . Содержит артефакты исполнения и сам сценарий.

- Обёртка платы(BoardWrapper) - прослойка между программой и физической платой. Абстрагирует функции связанные с подключением FPGA к сервера , прошивкой fpga и управление во время выполнение и сбор данных(waveform)

## Компоненты сервера :ну 
- Server - Основной класс сервера, инкапсулирующий и связывающиий между собой все остальные классы.
- Interpretator - модуль, отвечающий за интерпетацию команд командной строки.
- HwUnit - Модуль , отвечающий за работу с железом , обработку заданий на платах и и получения артефактов выполнения.
- IoUnit - Модуль , отвечающий за работу с потоками ввода/вывода.
- PersistenceUnit - Модуль , отвечающий за сохранения состояния сервера  в файл и восстановления данных сервера из этого файла.
- ClientHandler - Модуль обработчик комманд от клиентов, приходящих по сети.
- DataBaseUnit - ОПЦИОНАЛЬНО . Модуль общения с базой данных . Релизует функции загрузки и выгрузки сценариев и заданий в базу данных и паралельно загрузку и выгрузку файлов прошивки из файлового сервера.
